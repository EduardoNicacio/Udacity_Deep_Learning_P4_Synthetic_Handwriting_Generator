# Rubric

Use this project rubric to understand and assess the project criteria.

## Generative Model Architectures

### Criteria

Implement class-conditional logic in GAN architectures

### Submission Requirements

- `model/cgan.py` contains a Generator that successfully concatenates the latent vector z with a class embedding.
- `model/cgan.py` contains a `Discriminator` that integrates the class label with the image input tensor.
- Generator output uses a Tanh activation to produce 1x28x28 tensors in the [-1, 1] range.

### Criteria

Construct a Conditional U-Net for noise prediction

### Submission Requirements

- `model/diffusion.py` implements a ConditionalUNet that utilizes both a time-step embedding and a class label embedding.
- The architecture includes skip connections between the contracting (down) and expansive (up) paths.
- The model correctly outputs a noise prediction tensor of the same shape as the input noisy image.

## Model Training & Sampling

### Criteria

Implement adversarial training loops for cGANs

### Submission Requirements

- `01_cGAN_training.ipynb` implements the standard GAN minimax objective (BCE loss).
- The training loop includes a separate step for updating the Discriminator (on real and fake data) and the Generator.
- `01_cGAN_training.ipynb` displays a grid of generated digits (0-9) that clearly represent their respective class labels.

### Criteria

Implement forward and reverse diffusion processes

### Submission Requirements

- `02_diffusion_training.ipynb` implements the forward noising process ($q$ sampling) based on a linear or cosine beta schedule.
- The `sample_images` function implements the reverse iterative denoising loop from $T$ to $0$.
- The training objective correctly calculates the MSE loss between predicted and actual added noise.

## Evaluation and Data Utility

### Criteria

Evaluate generative performance via quantitative and visual metrics

### Submission Requirements

- `03_evaluation.ipynb` displays the computed FID score for both the cGAN and Diffusion model outputs.
- The notebook includes a side-by-side visual comparison showing "Real vs. cGAN vs. Diffusion" samples for at least 5 different digits.
- A markdown cell provides a brief analysis of which model produced higher fidelity and diversity.

### Criteria

Validate synthetic data utility through downstream tasks

### Submission Requirements

- `03_evaluation.ipynb` implements a CNN classifier that is trained using ONLY synthetic data generated by the models.
- The resulting classifier is tested against the **real** MNIST test set.
- The notebook reports the final accuracy achieved, demonstrating the practical "utility" of the synthetic handwriting.

## Suggestions to Make Your Project Stand Out

**Latent Space Exploration**: Implement a "walk" through the latent space by interpolating between two noise vectors and visualizing the smooth transition between generated digits.

**Advanced Diffusion**: Implement a more sophisticated noise schedule (like a Cosine schedule) and compare the resulting FID score to the standard linear schedule.

**Multi-Digit CAPTCHA**: Create a script that takes a 4-digit string and generates a composite CAPTCHA image using your best-performing model for each digit.

**Hyperparameter Analysis**: Provide a plot showing how the FID score changes as the number of diffusion timesteps (T) increases during sampling.
